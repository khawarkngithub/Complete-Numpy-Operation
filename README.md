# Complete NumPy Operations

This repository contains hands-on practice and examples for learning NumPy fundamentals and common numerical operations.

## Topics Covered

- NumPy array creation
- One-dimensional and multidimensional arrays
- Array data types
- `np.arange()`, `np.zeros()`, `np.ones()`, and `np.linspace()`
- Random arrays and random integers
- Indexing, slicing, reshaping, stacking, and splitting
- Matrix operations
- Array summation and data analysis examples

## Installation

Clone the repository:

```bash
git clone https://github.com/khawarkngithub/Complete-Numpy-Operation.git
cd Complete-Numpy-Operation
```

Create a virtual environment and install dependencies:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open `notebooks/numpy_operations_practice.ipynb` from the Jupyter interface.

## Requirements

- Python 3.10 or later
- NumPy
- Jupyter Notebook

## Learning Objectives

- Understand NumPy fundamentals
